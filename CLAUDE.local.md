# Local Overrides

Personal preferences and overrides that don't get shared via git.
Add anything here that's specific to your local setup.

## Git workflow (2026-09-17)
Dante werkt niet zelf in de terminal. Commit en push wijzigingen automatisch
(geen aparte toestemming per keer nodig), en pull bij de start van een sessie
om up-to-date te zijn. Blijf wel gewoon overzichtelijke, losse commits maken
met duidelijke messages — dit overschrijft alleen de "vraag eerst"-stap, niet
zorgvuldig commit-gedrag.
