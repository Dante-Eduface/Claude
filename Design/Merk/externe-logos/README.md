# Externe logo's

Logo's die niet van Eduface zijn. Eduface' eigen logo's staan in `../logos/`.

| Map | Wat |
|---|---|
| `scholen-nl/` | Nederlandse onderwijsinstellingen, SVG waar mogelijk |
| `scholen-uk/` | Britse onderwijsinstellingen |
| `concurrenten/` | Feedbackfruits, Graide, KEATH, Learnwise |
| `ongecropt/` | Ruwe varianten (PNG, WEBP, niet-bijgesneden SVG) van dezelfde logo's |
| `stockfotos/` | Ingekochte stockbeelden |

Gebruik de bijgesneden SVG uit `scholen-nl/` of `scholen-uk/`. Alleen als die ontbreekt val je terug op `ongecropt/`.
