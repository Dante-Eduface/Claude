# Context

Wie Dante is, wat Eduface is, waar de focus ligt. De vier bestanden met een `@` in `CLAUDE.md` worden elke sessie automatisch geladen.

- `me.md`, `eduface.md`, `current-priorities.md`, `open-vragen.md` : auto-geladen
- `personal.md` en `financien.md` : **niet** auto-geladen, alleen lezen bij echt persoonlijke taken
- `deep-work.md` : het werkritme, de blokken en het plafond. Niet auto-geladen, wel de bron voor alles over zijn agenda
- `kaart.md` : waar alles staat, wat waaruit leest, en hoe dingen heten
- `session-summary-sjabloon.md` : sjabloon om een sessie mee af te sluiten

**Vervallen op 19-09-2026:** `work.md` en `team.md` zijn samengevoegd tot `eduface.md`, en `goals.md` is opgegaan in `current-priorities.md`. Oude versies in `Archive/context-2026-09/`.

Hoe deze bestanden actueel blijven staat in `.claude/rules/context-onderhoud.md`.
