# Context

Wie Dante is, wat Eduface is, wie het team is, waar de focus ligt. De vijf bestanden met een `@` in `CLAUDE.md` worden elke sessie automatisch geladen.

- `me.md`, `work.md`, `team.md`, `current-priorities.md`, `goals.md` — auto-geladen
- `personal.md` — **niet** auto-geladen, alleen lezen bij echt persoonlijke taken
- `kaart.md` — waar alles staat, wat waaruit leest, en hoe dingen heten
- `session-summary-sjabloon.md` — sjabloon om een sessie mee af te sluiten
