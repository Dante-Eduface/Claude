# Regio iemt (Ierland + Malta), RFP-radar, stand 2026-09-29

Methode: TED Search API (api.ted.europa.eu/v3/notices/search, officiele TED-data, primair) voor alle notices buyer-country IRL en MLT vanaf 2024-01-01; etenders.gov.ie en etenders.gov.mt (EPPS) direct bevraagd en per koper gecrawld; detailpagina's van etenders geopend. TED-HTML/PDF/XML-pagina's geven een WAF-challenge (HTTP 202, leeg); de noticedata is daarom via de API gelezen (zelfde notice, velden: titel, omschrijving, waarde, deadline, winnaar). "Verifieerd" = noticedata via TED API of etenders-detailpagina zelf gelezen.

TED-URL-vorm: https://ted.europa.eu/en/notice/-/detail/<nr>
etenders-URL-vorm: https://www.etenders.gov.ie/epps/cft/prepareViewCfTWS.do?resourceId=<id>

## Hoofdbevinding

- Malta: geen enkele assessment/marking/exam-platform tender gevonden (alleen K-12 digital content en hardware).
