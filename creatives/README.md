# Creatives

Losse afbeeldingen die ik (Claude) genereer en die **niet** bij een specifiek project horen.

## Wat hier komt
- Algemene, losse creatives: Google Maps banners, losse social posts, snelle visuals, test-renders, alles zonder vaste projectthuis.

## Wat hier NIET komt
- Creatives die bij een project horen. Die gaan in `projects/<project>/creatives/`.
  - Voorbeeld: banner voor de Haagse Hogeschool webinar → `projects/haagse-hogeschool-webinar/creatives/`.
- Paid ads materiaal blijft staan in `projects/paid-ads-buildout/` (eigen structuur, niet verplaatsen).

## Regel
- Werk ik aan een specifiek project? → `creatives/` map binnen dat project (aanmaken als die nog niet bestaat).
- Is het een losse/algemene afbeelding? → hier in deze map.
